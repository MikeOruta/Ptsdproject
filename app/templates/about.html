Method

Logistic Regression estimates the probability of probable PTSD from ten inputs. It was chosen for being interpretable (every input has a visible weight), computationally light (suitable for low-resource settings) and well established in healthcare prediction.

  1. Cleaning: duplicates removed, spellings standardised, impossible values discarded.
  2. Missing values: filled with the median (numbers) or most common value (categories).
  3. Normalisation: numbers rescaled to a common scale.
  4. Encoding: gender converted to numeric indicator columns.
  5. Feature selection: only statistically significant inputs kept (p < 0.05).
  6. Training: 80/20 stratified split, 5-fold cross-validation, class weighting for the minority (PTSD) class.

The probability is mapped to a category: Low below {{ '%.0f'|format(risk_moderate * 100) }}%, Moderate from {{ '%.0f'|format(risk_moderate * 100) }}%, High from {{ '%.0f'|format(risk_high * 100) }}%.
